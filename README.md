# Facebook Messenger Triage Agent & Telegram Mini App

Autonomous Facebook Messenger triage system integrated with Telegram for interactive review.

## Features
- **⚡ Urgent Breakthrough**: Immediate triage for Marketplace buyer inquiries and VIP contacts.
- **✍️ AI Reply Proposals**: Conversational draft replies formatted for quick approval or editing.
- **📱 Telegram Mini App**: Full web UI for reviewing triage items on mobile or desktop Telegram.
- **🛡️ Secure Review**: Triage alerts presented directly in Telegram with Approve, Edit, and Dismiss actions.

## Telegram Mini App
The live web app is hosted via GitHub Pages and can be launched directly inside Telegram via  menu button.
